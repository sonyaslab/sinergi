====================================================================================================
BAGIAN 0. CARA MEMBACA
====================================================================================================
  Dua tahun dasar dihitung dengan SATU mesin hitung yang sama:
  - TD2010 = KBLI 2020, 21 kategori A-U. Ini jalur produksi sekarang.
  - TD2025 = KBLI 2025, 22 kategori A-V. Ini jalur rebasing, seri mulai 2019.
  Kategori M dan N selalu dipisah. Kategori R, S, T, U (dan V di TD2025) juga dipisah.
  Baris gabungan hanya ditampilkan sebagai kelompok publikasi dan tidak diinput:
  - TD2010: 'M,N' = M + N dan 'R,S,T,U' = R + S + T + U (format 17 kategori).
  - TD2025: 'TUV' = T + U + V (format ekspor LK 02 BPS).
  Pemetaan dari LK resmi TD2025: TUV.1 menjadi T.1, TUV.2 menjadi T.2, TUV.3 menjadi U, dan V =
    badan internasional (nihil).
  Satu item = satu komoditas/rincian dalam satu lapus, satu metode, dan satu wilayah.
  Operator boleh menambah atau menonaktifkan item per triwulan. Baris tabel pokok tidak pernah
    berubah karena item.

Tiga metode (rumus lengkap: docs/02_RUMUS_ENGINE.md)
  REV: Output ADHB = kuantum x harga; Output ADHK = kuantum x harga tahun dasar; NTB = (1 - rasio
    KA) x output.
      Angka diambil dari: lk.nilai_item seri KUANTUM, HARGA, RKA (+IH) ; jangkar di
        lk.parameter_item (RKA_TD, H_TD).
  EKS: baseline tahun dasar digerakkan indeks (IP: ADHK ikut indeks, ADHB = ADHK x IH/IH dasar; IB:
    ADHB ikut indeks, ADHK = ADHB / IH x IH dasar); NTB = (1 - rasio KA) x output.
      Angka diambil dari: lk.nilai_item seri INDEKS, IH, BASE_ADHB/BASE_ADHK (4 triwulan dasar), RKA
        ; lk.item.jenis_indeks ; lk.parameter_item RKA_TD.
  DEF: Output ADHB = nilai berlaku; Output ADHK = output / IH x IH dasar; NTB ADHB = input (atau (1
    - rasio KA) x output); NTB ADHK = (1 - rasio KA dasar) x output ADHK.
      Angka diambil dari: lk.nilai_item seri OUT_ADHB, NTB_ADHB, IH (+RKA) ; IH boleh dari
        lk.nilai_seri_referensi lewat lk.tautan_seri.

Jangkar tahun dasar = angka tahun dasar untuk menghitung ADHK:
  - TD2025: harga dan IH dasar dihitung otomatis dari data 2025. Rasio KA dasar diisi dari LK Biaya
    Antara (SE2026/SUT).
  - TD2010: harga dasar = harga 2010, IH dasar = 100, rasio KA = rasio LK lama.
  - Item yang tidak punya data tahun dasar WAJIB diberi jangkar. Tanpa jangkar, ADHK item itu
    menjadi 0.

Urutan hitung dan asal angka di backend:
  1. Item dan data dasar: lk.item, lk.nilai_item, lk.parameter_item.
  2. Rumus turunan dan tautan: lk.tautan_seri dan lk.nilai_seri_referensi.
  3. Hasil per item lalu per metode: lk.hasil_item, lk.hasil_metode (+ penyesuaian ADJ1/ADJ2/SC dari
     lk.penyesuaian tahap METODE).
  4. Rekonsiliasi per lapus: REV + EKS + DEF, + ADJ3, + ADJ4 (lk.penyesuaian tahap REKON), ditulis
     ke lk.hasil_lapus tahap BENC.
  5. Agregasi pohon: subkategori, kategori, kelompok, NTB/TOP/SOP/PDRB (ref.lapus,
     ref.lapus_kelompok).
  6. Simulasi pimpinan: lk.penyesuaian tahap SIMULASI, ditulis ke lk.hasil_lapus tahap FINAL.
  7. Tabel pokok: view lk.v_tabel_pokok, berisi semua baris pohon untuk setiap periode. Dashboard
     membaca view yang sama.

====================================================================================================
BAGIAN C. TABEL POKOK (format tetap, seperti Excel)
====================================================================================================
  Barisnya adalah seluruh pohon lapus, berurutan seperti Excel:
  - kategori (huruf tebal);
  - subkategori dan sub-subkategori (menjorok);
  - kelompok publikasi (bisa ditampilkan atau disembunyikan);
  - NTB, TOP, SOP, TOP.SOP, PDRB (TD2025) atau PDRB dan PDRB tanpa migas (TD2010).
  Baris yang belum punya hasil tetap tampil dengan sel kosong.
  Tab yang tersedia: ADHB, ADHK, distribusi, q-to-q, y-on-y, c-to-c, indeks implisit, laju implisit,
    sumber pertumbuhan (SoG), output ADHB, dan output ADHK.
  Rumus turunan:
  - distribusi = ADHB / PDRB ADHB x 100;
  - q-to-q = X(t) / X(t-1) x 100 - 100;
  - y-on-y = X(t) / X(t-4) x 100 - 100;
  - c-to-c = jumlah triwulan I s.d. t tahun ini / periode sama tahun lalu x 100 - 100;
  - implisit = ADHB / ADHK x 100;
  - SoG = perubahan X / PDRB ADHK periode pembanding x 100.
  Asal angka: lk.v_tabel_pokok (tahap FINAL). Pembanding angka rilis resmi: lk.tabel_pokok_rilis.

====================================================================================================
BAGIAN D. YANG PERLU DIKONFIRMASI TIM TEKNIS / METODOLOGI
====================================================================================================
  1. Rasio KA tahun dasar 2025 (LK Biaya Antara). Sekarang kosong di 17 lapus Put 0. Pilihan: diisi
     dari SE2026/SUT, atau angka sementara.
  2. Baris contoh templat di A.1.a dan A.1.b LK Put 0 (EKS Ubi Kayu, Semangka, Melon; DEF Ubi Jalar,
     Anggrek, Anthurium). Baris ini tidak dimasukkan ke templat dan harus dihapus juga di Excel.
  3. Pemisahan TUV: T.1 = TUV.1, T.2 = TUV.2, U = TUV.3, V = nihil. Bila PRT tercatat di TUV.1,
     pindahkan ke U.
  4. Item tanpa data 2025 (spesies ikan 2019-2021, emas 2019-2022, aluminium 2026) memerlukan
     jangkar pengganti atau sambungan ke item penerus.
  5. Metode dan sumber data pajak dan subsidi atas produk (TOP/SOP) untuk Kaltara.
  6. FBY atau CVM untuk rilis regional TD2025.
  7. TD2010: angka rilis 2019-2025 untuk diimpor sebagai riwayat; data N, T, U; indeks IBS/IMK
     2025-T3 dan sesudahnya.
  8. A.1.e (TD2025): usulan agar kuantum jasa pertanian ditautkan otomatis ke output A.1.a-A.1.d.
